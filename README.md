# Installation (Linux/Mac/WSL)
cd to your project folder

Activate your virtual environment (if you already created one):
`hackeurope/bin/activate`
`hackeurope/bin/.activate` (Mac)

Otherwise create your virtual environment:
`python -m venv hackeurope`

Install requirements:
`py -m pip install -r requirements.txt`
`pip install -r requirements.txt` (Mac)

# To run
`fastapi dev main.py`

# To get the docs
`http://127.0.0.1:8000/docs`
